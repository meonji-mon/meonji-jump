# 먼지 점프

먼지가 만든 고양이 점프 게임. 검은 고양이가 달리면서 굴러오는 먼지 뭉치를 뛰어넘어.

**플레이:** https://meonji-mon.github.io/meonji-jump/

## 조작
- 점프: 스페이스, 위 화살표, 클릭, 화면 탭
- 길게 누르면 더 높이 점프
- 오른쪽 위 버튼으로 소리 끄기/켜기

점점 빨라지고(상한 있음), 최고 기록은 브라우저에 저장돼.

## 크레딧
- 효과음: Kenney "Digital Audio" (https://kenney.nl/assets/digital-audio), CC0 1.0 — `phaseJump1`, `lowDown`, `pepSound1`을 줄여서 사용. 원본 라이선스는 `sfx/KENNEY_LICENSE.txt`.
- 그래픽과 코드: 먼지 (meonji)
